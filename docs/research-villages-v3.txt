##### The popular village overhauls (CTOV, Towns and Towers, Repurposed Structures) are NBT templates put together by jigsaw generation. Integrated Villages and qrafty's Japanese Villages also use hand-made templates. All of them stay inside vanilla's structure box: 257x257 blocks around the start, with jigsaw max_distance_from_center at most 116-128. CTOV uses 80 and YUNG's API hard-codes 128, so none of these villages is bigger than NOIRM's capital already is. They look good because of cheap tricks that repeat across every building: weighted block randomizers (cracked, mossy or path variants at 15-30%), one house design recoloured through several processor lists, weighted pools that include empty slots and decor features, roads that follow the terrain next to houses that stay rigid, and foundation pillars or stilts that reach down to the ground. The settlements that are really big are generated chunk by chunk from a layout that is fixed by the seed and cached. Lost Cities does this with a Feature in every overworld chunk, cutting the terrain into city levels 6 blocks apart joined by stair streets. Large Structure Lib does it with a grid placement that makes every chunk its own structure start and returns only that chunk's slice of a pre-generated layout. NOIRM already works the same way (seed, cached plan, builder per chunk), so extra 'ward' starts around the existing capital could take capitals to 500-700 blocks and keep /locate and beard_thin terrain adaptation working. In other mods the life comes from NPC systems more than from blocks. Millénaire has goals with priorities, leisure only when no work is possible, marked spots in each building, two-person dialogues and buildings that upgrade. MineColonies has citizen states for eating at a restaurant, going to hospital and mourning, and makes citizens sit at tagged seats by riding an invisible SittingEntity. MCA has tick-based schedules (night owls, day and night guard shifts), personalities, genetics and rumours. Guard Villagers' guards hunt hostile mobs, guard patrol points and form shield lines, and Living Villages adds face-to-face talk, sheltering from rain and campfire nights. I found no Naruto mod that generates hidden villages procedurally: the existing ones ship a few hand-built buildings, or the village is a fixed map. Konoha fan maps agree on motifs NOIRM still lacks: canals with red-railed bridges, lantern-lit alleys, gated compounds, misty streets and rooftops you can run across. Suggested order: first the cheap visual passes (block variety, colourways, facades, rooftop clutter, filling the lawns), then marked spots with schedules, conversations and guards that fight monsters, then terraces and per-chunk wards for size, and last growth, roads and sound.

##  Go past the 250-block cap: give every village chunk its own structure start (grid/ward placement) [ high large ]
Why: vanilla structures cover at most 257x257 blocks around their start (jigsaw max_distance_from_center 1-128, or 116 with terrain_adaptation). YUNG's API hard-codes MAX_TOTAL_STRUCTURE_RADIUS = 128 and CTOV's large villages use 80, so every jigsaw village mod stays inside that box. Two projects get past it, and both generate chunk by chunk from a fixed, cached layout. (a) Large Structure Lib registers a StructurePlacement 'largestructlib:grid' whose isPlacementChunk() always returns true. Its findGenerationPoint() maps the chunk to a grid cell ((maxDistanceFromCenter>>4)+padding)*2 chunks wide, generates the whole layout once per cell (a map cache that drops cells two away) and returns only this chunk's part; its radius goes up to 4096. It is MIT-licensed, for 1.21.1 NeoForge, but the same API exists in 1.20.1. (b) Lost Cities skips structures entirely: a Feature is added to #minecraft:is_overworld (forge:add_features, step raw_generation, placed feature count 1) and decides what each chunk holds from the seed and the chunk coordinates.
NOIRM recipe (keeps /locate and beard_thin):
1. Keep hidden_village as the core start.
2. Add a structure 'noirm:village_ward' with a WardPlacement registered in Registries.STRUCTURE_PLACEMENT (codec built with StructurePlacement.placementCodec).
3. isPlacementChunk(state,cx,cz): for the capital spacing cells around (cx,cz), compute the anchor with new RandomSpreadStructurePlacement(64, 32, LINEAR, 718236451).getPotentialStructureChunk(state.getLevelSeed(), cx, cz), the same numbers as hidden_villages.json. Return true only if the chunk is outside the core's chunks and within the ward radius (for example 20 chunks, about a 650-block capital). Never let core and ward draw the same chunk, or spawns duplicate.
4. findGenerationPoint: build a GenerationContext for the anchor chunk. The same seed gives the same WorldgenRandom, so the rotation and village seed match the core. Re-run the existing site test and biome check once per anchor, cached in a bounded ConcurrentHashMap. Then return a VillagePiece whose BoundingBox is this chunk only (16x16, ground to ground+height). VillageBuilder.build(clip) already draws only what intersects the clip.
5. Ward biome tag: #minecraft:is_overworld, because validity comes from the anchor.
6. Raise ninja_settlements' exclusion_zone from 12 to the ward radius + 4.

##  Break up every surface with weighted block pickers keyed to the block position [ high small ]
All the overhaul mods vary flat textures with weighted randomization:
- CTOV rule processors: stone_bricks becomes cracked 30% / mossy 30%; smooth_quartz becomes quartz_block 30% / quartz_bricks 30%; dirt_path becomes cobblestone 30% / mossy_cobblestone 30%; oak_planks becomes stripped_oak_log 15%.
- YUNG's BlockStateRandomizer: a list of entries with probabilities, and the default state takes the rest. Stone bricks are 50% mossy / 25% cracked, and the processors keep stair, slab and wall states (getStairsBlockWithState).
- Lost Cities palettes: weighted 'blocks' lists filling a 128-slot table, plus a 'damaged' variant for each material.
- RS path_randomizer: 10% of dirt_path becomes grass, and path over water becomes planks.
- Vanilla rule processor: the axis_aligned_linear_pos predicate changes the chance with height.
NOIRM: turn VillagePalette slots into Material objects. BlockState pick(x,y,z) makes a weighted choice from a hash of world x,y,z plus the village seed, so the result is the same across chunk borders and regenerations. For stairs, slabs, walls and logs, copy the properties (withPropertiesOf).
Suggested Leaf sets:
- roof tiles: orange_terracotta 80 / red_terracotta 12 / brown_terracotta 8
- streets: dirt_path 60 / coarse_dirt 15 / gravel 10 / packed_mud 15
- stone walls and the great wall: stone_bricks 55 / cracked 15 / mossy 20 / andesite 10, with double the mossy chance in the bottom 2 rows
- timber: stripped_spruce_log 85 / spruce_log 15
- plaza: stone_bricks 70 / polished_andesite 20 / cracked 10
The cost is one hash per block, and every building improves at once.

##  Colourways: one building design, many colour schemes [ high small ]
CTOV's fortified plains village reuses the same house NBTs through three recolouring processor lists (pink_house, quartz_house, red_house). MineColonies re-skins every building type across 23 built-in style packs (acacia ... pagoda ... warped), each building with levels 1-5, so one design reads as many.
NOIRM: give each palette a list of Colourway {wall, wallAccent, roof, roofTrim, timber, curtain/awning colour}. VillagePlanner picks one per lot from the seed, weighted by ward. Rule: it must differ from both neighbours on the same street (re-roll up to 3 times). Buildings read colours from the lot's colourway, not the palette directly.
Leaf example:
- walls: white (smooth_quartz or calcite), cream (birch planks or smooth_sandstone), warm terracotta
- roofs: orange, red, brick, rare teal
- timber: spruce, dark oak, stripped birch
4 walls x 4 roofs x 3 timbers gives 48 combinations, which removes the copy-paste look visible in r5-leaf-streets.png. Sand: sandstone, red sandstone and terracotta tones. Snow: spruce and dark oak with blue, cyan and grey roofs.

##  Kill the lawns: tight lot packing plus yard fillers [ high medium ]

- 3x3 or larger: a filler from a weighted list. ##  Facades with depth: per-floor modules, recessed windows, eaves and street fronts [ high medium ]

5. Middle floors: plain, balcony (fence + slab) or bay.
6. Top: roof garden, water tank, laundry or signboard.
Pick modules per floor with ground/middle/top context and lot type, the same way Lost Cities picks floor parts.

##  Face-to-face conversations with speech bubbles, greetings and gossip [ high medium ]
How other mods do it:
- Millénaire GoChat: a villager who is 'socialising' gets joined by another within 5 blocks (distance squared < 25). Both get a two-role dialogue, and only one subtitled conversation runs per ~5-block area.
- Living Villages (1.20.1): villagers stop, face each other and take turns with speech bubbles, in groups of 3-4 on pre-written topics. Greetings change by morning, afternoon and evening. Villagers run to shelter in rain, gather at campfires at night, and children play tag. Each villager tracks your reputation.
- Vanilla gossip: a trade gives +4 (max 25), an attack gives minor_negative 25, values decay every 20 minutes, and gossip spreads when villagers talk.
NOIRM:
- A conversation is 2-4 NPCs at a MEET or SEAT POI or a stall front. Speakers alternate every 60-80 ticks, look at each other, and make a small gesture via NpcAnimator.
- Lines come from lang keys village.talk.<topic>.<n> in en_us, es_es and es_mx. The topic depends on context: time, weather, an alarm raised today, the player's clan or rank, or a festival.
- Show each line as a vanilla minecraft:text_display entity (Java 1.19.4+; NBT text, background ARGB, line_width, shadow, billboard center) 0.5 blocks above the speaker for ~3 s, at most one per 6 blocks. Or show it as a subtitle when the player is within 6 blocks.
- Add a per-village reputation, raised by trades and help in fights and lowered by attacks, that conversations spread and time decays. It extends the existing alarm.

##  Terraces instead of one flat floor: height levels, retaining walls and stair streets [ high large ]
How other mods do it:
- Lost Cities never flattens a whole city to one height. Each chunk gets a 'city level' from its heightmap averaged with sampled neighbours. Thresholds are every 8 blocks of terrain (cityLevel0Height 75, 83, 91, ...), and level n's ground is GROUNDLEVEL 71 + n x 6 (FLOORHEIGHT). A street that changes one level uses a dedicated 'stair' street part.
- Vanilla, RS and CTOV roads use the 'terrain_matching' projection (gravity processor) while houses stay rigid.
- MineColonies' pagoda style ships retaining-wall decorations (small, medium and large, in bricks or cobble).
NOIRM:
1. In VillagePlanner, sample getBaseHeight(OCEAN_FLOOR_WG) on an 8-block grid over the plan. This uses noise only and needs no loaded chunks.
2. Blur 3x3, then cut into steps of 4-5 blocks (about one STOREY) relative to the anchor.
3. Each lot takes the level of its centre cell; each street cell keeps its own.
4. Where two levels meet, build a retaining wall: stone bricks with 30% mossy/cracked, a cobblestone/andesite footing row, a stone-brick-slab cap, and vines on ~20% of the face.
5. Where a street crosses a level edge, build a 3-5-wide flight of stone brick stairs with lantern posts, or a slab ramp for 1-block steps. Never run a level edge through a lot.

Villages then fit hills and valleys, and the skyline rises in layers toward the Kage Rock.

2. NPC work sounds: anvil or grindstone use at the weapon shop every 5-15 s, page turns at the scroll shop, eating at the ramen counter, and a priest NPC ringing the shrine bell at dawn (time 0) and dusk (12000).
3. A small client controller active inside a village area (send the bounds over the existing packets): daytime birds (parrot ambient, very quiet), wind chimes (note_block chime on random notes from a pentatonic scale) near eaves, and a drum (note_block basedrum) on festival nights. Fade in and out over 5 s.

##  Roads between settlements, with travellers [ medium large ]

##  Generic 'drum with flared ring eaves' recipe for round buildings (the Konoha signature) [ high medium ]

Add 2–3 'bay' boxes (3 wide, 2 deep, 3 high, same wall block, glass pane, stair pent roof) sticking out at random angles on each floor. For big buildings, union 2–3 disks of different r and height. Optional 'cables': a ring of chain or iron_bars one block outside the wall at mid-storey. The Forest of Death tower variant uses 5–6 tiers and a shroomlight lantern hung on a chain from a fence arm.

##  Guardrails: performance limits and IP-safe motifs [ medium small ]
Performance: keep decoration as plain blocks and avoid entities (item frames, armor stands, boats) except a few seat entities. Cap block entities per capital: banners and noren around 300, signs and hanging signs around 150, decorated pots around 60. Cap lit campfires at about 30, because each one emits smoke particles every tick. Use Blocks.LIGHT for invisible interior lighting instead of extra lantern block entities. Lit windows are plain stained glass. Use WAXED copper variants so roof colours don't change, and remember that vines spread over time. With Fire Release and terrain destruction in play, wooden walls burn, which is another reason to build the great wall from terracotta. 1.20.1 has no tuff bricks, polished tuff, copper grates or copper bulbs (I checked the client jar); froglights, mud bricks, bamboo, cherry, hanging signs and decorated pots are all available. IP: do not reproduce franchise emblems (leaf swirl, hourglass, four waves, cloud bars, stone wedges, clan crests), canon shop names or character likenesses. Use NOIRM's own 5×5 glyphs, generic kanji and kana (医, 上, 土, 湯, ラーメン, あ/ん), generic crests and generic statue silhouettes. This research describes motifs only; nothing here was copied into src/.
