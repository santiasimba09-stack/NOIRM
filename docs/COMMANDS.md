# NOIRM commands

Every command starts with `/noirm`. In the game, `/noirm help` lists these sections and `/noirm help <section>` lists their commands; click one to type it. ⚑ = needs cheats (single-player with cheats on, or an operator). To run one for someone else: `/execute as <player> run noirm …`.

_This file is generated by `tools/docs/gen_commands.py` from `CommandGuide.java`._


## me — You: profile, healing, stats, Resolve

| Command | What it does | Example |
|---|---|---|
| `/noirm me` | everything about you: clan, bars, stats, style, eyes, beast, crew | `/noirm me` |
| `/noirm me heal` | full health, chakra, stamina and food; no cooldowns or bad effects ⚑ | `/noirm me heal` |
| `/noirm me max` | every stat to the maximum, then heal ⚑ | `/noirm me max` |
| `/noirm meditate` | sit down to meditate (or stand up): fast chakra, Reserves training and nature energy; key N | `/noirm meditate` |
| `/noirm me nature <0-100>` | set your nature energy ⚑ | `/noirm me nature 50` |
| `/noirm me stats <speed> <taijutsu> <vitality> <reserves> [<ctl> <wil>]` | set the four core stats at once (and optionally chakra control and willpower) ⚑ | `/noirm me stats 30 40 25 20 15 15` |
| `/noirm stat <speed\|taijutsu\|vitality\|reserves\|ctl\|wil> <1-100>` | set one stat (ctl = chakra control, wil = willpower) ⚑ | `/noirm stat ctl 50` |
| `/noirm stats` | show your chakra and stamina | `/noirm stats` |
| `/noirm set <chakra\|stamina> <value>` | set your current chakra or stamina ⚑ | `/noirm set chakra 80` |
| `/noirm max <chakra\|stamina> <value>` | set your maximum chakra or stamina ⚑ | `/noirm max chakra 300` |
| `/noirm refill` | fill chakra and stamina ⚑ | `/noirm refill` |
| `/noirm resolve <0-100>` | set your Resolve (100 = ready to awaken) ⚑ | `/noirm resolve 100` |
| `/noirm awaken` | awaken right now ⚑ | `/noirm awaken` |
| `/noirm creator` | reopen the character creator to change your look (clan and stats stay) | `/noirm creator` |
| `/noirm creator height <0.85-1.15>` | change only your height (the hitbox follows) | `/noirm creator height 1.1` |
| `/noirm creator reroll` | the character creator again, with fresh clan rolls ⚑ | `/noirm creator reroll` |
| `/noirm creator skip` | finish character creation right away with the look so far ⚑ | `/noirm creator skip` |
