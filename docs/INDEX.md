# Docs index

One line per doc: what it's for and when to read it. Sizes in KB, so you can judge the cost. For big docs, read only
the part you need: `python3 tools/dev/docsec.py docs/X.md` prints the outline, `... docs/X.md "heading words"` one section.

## Start here
| Doc | KB | What / when |
|---|---|---|
| `../CLAUDE.md` | 7 | Project rules and commands. Always (loaded automatically). |
| `INDEX.md` | 5 | This list. Always. |
| `STATUS.md` | 3 | The dashboard: current version, in progress, next steps, flaky tests. Read when planning or briefing. |
| `../.claude/skills/*/SKILL.md` | 2-5 each | Step-by-step recipes (helper rules, add a jutsu/entity/command/clan perk, game tests, models, textures, merging, releasing). Read the one for your task. |
