# Clans: research index

The canon research for every clan, one file per clan, so a helper reads only the clan it builds
(it used to be one 132 KB file, `CLAN_RESEARCH.md`). Each clan file has Part I (canon facts, databook
profile, costs, progression, our game-changer mechanics, sources) and, where written, Part II (the bold
reading). What is **built** lives in [`../CLANS.md`](../CLANS.md); the Aburame and the Inuzuka have their
own design docs ([`../ABURAME.md`](../ABURAME.md), [`../INUZUKA.md`](../INUZUKA.md)).

- [`_overview.md`](_overview.md): source tags, NOIRM numbers, the owner's bold-reading brief, the summary table, the family tree, databook stats. Read it once per clan task.
- [`balance.md`](balance.md): clans we lack, the power ranking, how each tier balances, shared systems, corrections to older docs, things hard to confirm, the smaller clans' bold hooks.
