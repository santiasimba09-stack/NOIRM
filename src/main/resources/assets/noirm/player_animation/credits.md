# Player animation credits

Every animation in this folder is NOIRM's own, generated by `tools/animgen/gen_anims.py`
(poses and timing written for this mod; see `tools/animgen/motion.py`).

Earlier versions used eight animations from **Boundless / Strongest** by **LeBoundlessJame**
(MIT License, kept in `license_boundless.txt` for the record): quick_jab, turning_hook,
rotating_kick, counter_kick, aerial_flip_kick, rising_uppercut, forward_roll, backward_roll.
Those files have since been replaced with new ones under the same names.
